# 🎯 HOW TO RUN OTZARIA ON WINDOWS

## Instant Start ⚡

### Option 1: Just Run (Fastest)
```
Double-click: otzaria.exe
```
**Done!** Application launches immediately.

---

### Option 2: Install (User Friendly)
```
Double-click: otzaria_setup.exe
Follow the installation wizard
Done!
```

---

## System Requirements

- **OS:** Windows 10 or later (64-bit)
- **RAM:** 2GB or more
- **Disk Space:** 500MB free
- **Internet:** Not required ✓

---

## Troubleshooting

### Application won't start?
1. Ensure all files from Release folder are present
2. Try right-click → "Run as Administrator"
3. Restart your computer
4. Update Windows

### Getting an error message?
1. Note the exact error
2. Check if it mentions missing DLL files
3. Ensure complete Release folder was copied
