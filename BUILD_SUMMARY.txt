================================================================================
                          DISTRIBUTION OPTIONS
================================================================================

OPTION A: Direct EXE (Portable)
  • Copy: build\windows\runner\Release\*
  • Size: ~150-200MB (with all DLLs)
  • Advantages: No installation, instant launch
  • Disadvantages: Larger file size

OPTION B: Installer (Professional)
  • Copy: Output\otzaria_setup.exe
  • Size: ~50-80MB
  • Advantages: Smaller, professional, creates shortcuts
  • Disadvantages: Requires installation

RECOMMENDATION:
  Use the installer (Option B) for:
  • Distribution to multiple users
  • Professional appearance
  • Smaller download/transfer size
  • Easy uninstall

================================================================================
                          TROUBLESHOOTING
================================================================================

ISSUE: "Flutter not found"
SOLUTION:
  1. Install Flutter: https://flutter.dev/docs/get-started/install/windows
  2. Add to PATH: setx PATH "%PATH%;C:\flutter\bin"
  3. Restart Command Prompt
  4. Run: flutter --version (verify)
  5. Try build again

ISSUE: "Visual Studio build tools not found"
SOLUTION:
  1. Download: https://visualstudio.microsoft.com/downloads/
  2. Install "Desktop development with C++" workload
  3. Restart computer
  4. Try build again

ISSUE: "Build failed" (generic error)
SOLUTION:
  1. Run: flutter clean
  2. Run: flutter pub get
  3. Try build again
  4. If still fails, check Flutter doctor: flutter doctor -v

ISSUE: "Inno Setup not found"
SOLUTION:
  - This is OK - build still succeeds!
  - EXE is ready in: build\windows\runner\Release\otzaria.exe
  - Installer creation skipped
  - To create installer, install Inno Setup: https://jrsoftware.org/isdl.php

ISSUE: "Application won't start on target PC"
SOLUTION:
  1. Ensure entire Release folder was copied
  2. Check all DLL files are present
  3. Verify target PC is Windows 10 or later
  4. Try running as Administrator
  5. Restart the computer
